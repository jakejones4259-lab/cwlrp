# Cake Wallet Web

A web-based simulation of Cake Wallet.

## Features
- PWA support (Add to Home Screen)
- Offline capability
- Simulation of Monero wallet interface (`larpxmr.html`)

## Deployment
This site is ready for GitHub Pages.
1. Upload/Push files to a GitHub repository.
2. Go to Settings > Pages.
3. Select 'Deploy from branch' and choose 'main' (or 'master') and root folder '/'.
